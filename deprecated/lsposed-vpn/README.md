# Deprecated LSPosed VPN Backend

This directory is a source-only snapshot of the retired application-process libxposed VPN module
and its hook-free policy model. It has no supported build entry point, APK export, LSPosed scope
workflow, device test, maintenance commitment, compatibility guarantee, or security claim.

The snapshot is intentionally absent from the root Gradle and Make graphs. Do not install it as a
ZygVeil component or use its historical evidence to accept the supported system-server backend.
